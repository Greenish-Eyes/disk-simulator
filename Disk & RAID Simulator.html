Crash consistency: journaling

Workload (chapter 42): append one 4 KB block to a file, which needs three writes: data block Db, bitmap B[v2] and inode I[v2]. Pick a mode and what reached the disk before the crash.

LFS segment cleaner

Four files a–d (4 blocks each) are written to the log, then overwritten blocks are appended to new segments (4 blocks per segment). ’ marks a rewritten version; struck-through blocks are dead.

SSD: FTL & garbage collection

Log-structured page-mapped FTL. Writes append to the active block; overwrites leave dead pages; when free blocks run low, GC copies live pages out of the emptiest block and erases it. Cells: logical page number (green = live, struck = garbage, E = erased).
